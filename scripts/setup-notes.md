This repository is already bootstrapped. Follow `README.md` for independent frontend/backend startup and `docs/integration/team-workflow.md` for independent clones. After the initial main commit, `sh scripts/create-lane-branches.sh` creates five local branch refs from one main SHA without switching checkout or overwriting existing branches. Worktrees are not required. `sh scripts/dev.sh` starts only the backend; run `npm run dev` separately in frontend. No script pushes or chooses a GitHub remote.
