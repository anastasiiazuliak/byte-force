# Data sources

The current source catalog, attribution and quality policy are in [Data and science](DATA_AND_SCIENCE.md). This stable reference is retained for data/pipeline documentation.

## Audit caveat

The reviewed 80–90°S LOLA source is identity-bound and supports regional terrain calculations, not certified global visibility. Derived scene geometry and illustrative celestial objects do not establish physical ground truth. LROC image overlap must be checked independently; no verified texture is applied to the three native patches.
