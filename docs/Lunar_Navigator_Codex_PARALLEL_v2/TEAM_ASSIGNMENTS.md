## Як користуватись

1. Відкрий `people/PERSON-0N.md` зі своїм номером — там повний список твоїх задач та посилання на кожен промт.
2. Одразу запускай свій **повний lane prompt** із `prompts/PERSON-0N-PASTE-INTO-CODEX.md` у своїй worktree; виконуй спочатку **P0**, не запускай P1/P2, поки критичний наскрізний сценарій не працює.
3. Для GitHub Issue постав реального учасника в **Assignees**; використай `assignee_number` в `issues.csv` для розподілу.
4. Перед передачею таски Codex надай `issues/TASK-ID.md` і `docs/TEAM_SPEC.md`; агенту не дозволяється довільно змінювати чужі модулі.
